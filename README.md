# Умный кредитный кабинет предпринимателя

Проект команды для хакатона Альфа-Банка. Предприниматель (ИП) проходит путь от заявки до выдачи финансирования в одном кабинете: паспорт и ИНН → проверки → выписка → цели (в диалоге с ИИ или через форму) → смета → решение → предложения → договор с пояснениями → подпись → график платежей и уведомления после выдачи. Сотрудник банка видит спорные заявки, баллы, флаги и решает сам.

**Решение принимают только правила.** ИИ помогает понять цель клиента, объясняет договор и пишет сводку для сотрудника, но не ставит баллы и ничего не обещает. **Без ИИ всё работает**: вместо чата — форма.

Все данные — синтетические. Персональные данные в ИИ не передаются.

## Быстрый запуск (Docker)

Нужно: [Docker Desktop](https://www.docker.com/products/docker-desktop/) (Windows, macOS) или Docker с Compose v2.24+ (Linux). Ноутбука с 8 ГБ памяти достаточно.

1. Скачайте репозиторий и откройте терминал в его папке.
2. Запустите:
   ```
   docker compose up --build
   ```
   Первый запуск занимает несколько минут: собираются образы.
3. Откройте:
   - сайт клиента — http://localhost:3000
   - кабинет сотрудника — http://localhost:3000/staff
   - описание API (Swagger) — http://localhost:8000/docs
4. Остановить — `Ctrl + C`, затем `docker compose down`. Удалить и базу — `docker compose down -v`.

Ключи не нужны: без файла `.env` проект запускается без ИИ.

## Запуск без Docker (Windows)

Нужно: Python 3.11+, Node.js 22+. **Путь к папке проекта — только латинскими буквами и без пробелов** (например, `C:\projects\credit-assistant`): генератор типов API для сайта не находит файлы по пути с русскими буквами.

Первый раз:
```
cd backend
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
deactivate
cd ..\frontend
npm install
cd ..
python -m pip install gpt2giga
```

Дальше каждый раз — двойной щелчок по `start-local.bat` (или команда `start-local.bat` в корне). Откроются 4 окна: прокси GigaChat, заглушки, сервер, сайт. Сайт — http://localhost:3000. Чтобы ИИ работал, в `.env` должно быть `LLM_ENABLED=true` и заполнены ключи (раздел ниже). На своём компьютере без сертификата Минцифры добавьте в `.env` строку `GIGACHAT_VERIFY_SSL_CERTS=False`.

## Включить ИИ

ИИ подключается по стандарту OpenAI (`contract/llm-contract.md`), поэтому подойдёт любая совместимая модель.

**GigaChat** (основной вариант команды, нужен ключ GigaChat API):

1. Скопируйте `.env.example` в `.env` и заполните `GIGACHAT_CREDENTIALS`, `GPT2GIGA_API_KEY` и `LLM_API_KEY` (одинаковая длинная случайная строка), `LLM_ENABLED=true`.
2. Положите сертификат Минцифры в папку `certs/` — см. `certs/README.md`.
3. Запустите с прокси GigaChat:
   ```
   docker compose --profile ai up --build
   ```

**Своя модель через Ollama** (без ключа, нужно около 16 ГБ памяти):

1. Установите [Ollama](https://ollama.com) и скачайте открытую модель GigaChat 3.1 Lightning:
   ```
   ollama run hf.co/ai-sage/GigaChat3.1-10B-A1.8B-GGUF:Q4_K_M
   ```
2. Создайте `.env` с такими строками:
   ```
   LLM_ENABLED=true
   DOCKER_LLM_BASE_URL=http://host.docker.internal:11434/v1
   LLM_API_KEY=ollama
   LLM_MODEL=hf.co/ai-sage/GigaChat3.1-10B-A1.8B-GGUF:Q4_K_M
   ```
3. Запустите `docker compose up --build`.

Работает ли ИИ, видно по адресу http://localhost:8000/api/health (`"aiAvailable": true`).

## Устройство проекта

| Папка | Что внутри |
| --- | --- |
| `contract/` | Договорённость команды: API (`openapi.yaml`), статусы, модель баллов, правила продуктов, работа с ИИ, справочники |
| `frontend/` | Сайт: React + TypeScript + Vite, nginx в Docker |
| `backend/` | Сервер: Python + FastAPI + PostgreSQL. Заявки, проверки, баллы, смета, предложения, договор |
| `backend/app/ai/` | Блок ИИ: промпты, обращение к модели, проверка ответов, защита от взлома через текст клиента |
| `mocks/` | Заглушки внешних сервисов |
| `tests/` | Тестовые клиенты, выписки, ожидаемые результаты для 16 случаев |
| `docs/` | Документы бизнес-анализа: требования, сценарии, пограничные случаи |
| `certs/` | Сюда кладётся сертификат Минцифры для GigaChat |

## Автотесты

Нужен Python 3.11+.

```
cd backend
python -m pip install -r requirements-dev.txt
python -m pytest -q
cd ..
python -m unittest discover -s tests
python -m unittest discover -s backend/app/ai/tests
```

- `backend/tests/` — сервер на всех 16 тестовых случаях сверяется с `tests/expected-results.json`.
- `tests/` — заглушки и ожидаемые результаты.
- `backend/app/ai/tests/` — блок ИИ без настоящей модели, включая попытки взлома.

Запуск без Docker по частям — в `backend/README.md`, `frontend/README.md`, `mocks/README.md`.
