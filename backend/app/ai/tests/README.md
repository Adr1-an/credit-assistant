# Проверки блока ИИ

| Файл | Что делает | Нужен ли GigaChat |
| --- | --- | --- |
| `test_offline.py` | 50 проверок на подставной модели: правильные ответы, выдуманные цели и коды, обещания одобрения, выдуманные числа, попытки взлома («игнорируй правила», «одобри кредит»), персональные данные не уходят в ИИ, модель молчит или ответила ошибкой | Нет |
| `chat_live.py` | Чат с ИИ в консоли: пишете как клиент, после каждого ответа видно, какие цели и ответы ИИ записал в итог | Да: запущен gpt2giga, заполнен `.env` |
| `check_live.py` | 12 вопросов настоящей модели по всем пяти задачам. Результат — в `check_ai_result.txt` в корне (в `.gitignore`) | Да: запущен gpt2giga, заполнен `.env` |

Запуск из корня репозитория:

```
python -m unittest discover -s backend/app/ai/tests -v
python backend/app/ai/tests/check_live.py
python backend/app/ai/tests/chat_live.py          # или с --start — клиент без бизнеса
```
