# Блок ИИ (`backend/app/ai/`)

Владелец папки — человек 4. Бэк только вызывает функции отсюда и ничего внутри не меняет. Правила — `contract/llm-contract.md`.

## Что здесь

| Файл | Что делает |
| --- | --- |
| `__init__.py` | Пять функций для бэка: `dialog_step`, `suggest_okved`, `categorize_transactions`, `explain_contract`, `staff_summary`, плюс `is_available()` и `AIUnavailable` |
| `prompts/*.md` | Инструкции для модели, по одной на задачу. Править текст можно здесь, код трогать не нужно |
| `client.py` | Запрос к модели по стандарту OpenAI (gpt2giga, Ollama и другие) |
| `validate.py` | Проверка ответов модели: только известные цели, вопросы, коды и категории, правильные типы и границы чисел |
| `guard.py` | Защита: текст клиента — данные, а не команды; запрет обещаний и выдуманных цифр; персональные данные в ИИ не уходят |
| `config.py` | Настройки из переменных окружения |
| `errors.py` | `AIUnavailable` |
| `tests/` | Проверки: без модели (`test_offline.py`) и на настоящем GigaChat (`check_live.py`), см. `tests/README.md` |

Внешние пакеты не нужны — только стандартная библиотека Python 3.10+.

## Настройки

| Переменная | Пример | Что значит |
| --- | --- | --- |
| `LLM_ENABLED` | `true` | Без неё (или без `LLM_BASE_URL`) ИИ выключен и бэк показывает форму |
| `LLM_BASE_URL` | `http://gpt2giga:8091/v1` | Адрес прокси |
| `LLM_API_KEY` | ключ прокси | Значение `GPT2GIGA_API_KEY`. Не ключ GigaChat |
| `LLM_MODEL` | `GigaChat-2-Max` | Модель |
| `LLM_TIMEOUT_SECONDS` | `30` | Дольше — «ИИ недоступен» |
| `LLM_TEMPERATURE` | `0.2` | Стабильность ответов |

Ключи хранятся только в `.env` на сервере. В репозитории — `.env.example` с пустыми значениями.

## Как это работает

1. Функция собирает промпт: инструкцию из `prompts/`, служебные данные и текст клиента внутри `<client_text>`.
2. Просит модель ответить JSON по схеме (`response_format: json_schema`). Если прокси такое не принимает — один раз повторяет без схемы и дальше просит JSON словами.
3. Проверяет ответ. Что-то не так — бросает `AIUnavailable`, и бэк включает запасной вариант.

Что считается «не так»:
- модель выключена, молчит дольше тайм-аута, ответила ошибкой или не JSON;
- цель, вопрос, код ОКВЭД, категория или строка выписки не из списка;
- значение не того типа или вне границ;
- обещание одобрения, ставки или процента в диалоге;
- число в объяснении договора, которого нет в договоре;
- решение «одобрить / отказать» или выдуманное число в сводке для сотрудника.

## Изменения

- **1.3.** Сводка для сотрудника: модель заполняет поля по темам (риск, баллы, выписка, смета, чего не хватает). Если заполнила меньше 3, код сам добавляет готовые факты из карточки: флаг, балл и зону, самый слабый блок, доход по выписке, подсказку системы. Ничего не придумывает. Из ответа по договору убирается служебное `foundInContract`, если модель вписала его в текст.
- **1.2.** Кнопки для вопросов с выбором и «да/нет» подставляет код (`validate.OPTION_LABELS`), модель получает подписи вариантов.
- **1.1.** `"null"` строкой считается пустым значением. При непонятной цели можно переспросить (`ASKING`, `currentQuestionId: null`). Коды на кнопках не показываются.
