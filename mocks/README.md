# Заглушки внешних сервисов

Маленький сервис, который отвечает серверу вместо настоящих внешних систем: реестр ИП (ЕГРИП), налоги, бюро кредитных историй, приставы, реестр банкротств, проверка паспорта. Правила ответов — `contract/mocks-contract.md`.

## Что в папке

| Файл | Что это |
| --- | --- |
| `app.py` | Сервис на FastAPI (основной запуск) |
| `logic.py` | Вся логика ответов |
| `devserver.py` | Тот же сервис без установки пакетов (запасной запуск) |
| `Dockerfile`, `requirements.txt` | Для запуска в Docker |
| `data/*.json` | Ответы каждого сервиса по каждому тестовому человеку. Создаются скриптом `tests/build_seed.py`, руками не править |

## Запуск

**В Docker** (основной способ; бэк обращается по адресу `http://mocks:8090`). Добавить в `docker-compose.yml`:

```yaml
  mocks:
    build: ./mocks
    ports: ["8090:8090"]
```

**Без Docker:**

```
pip install -r mocks/requirements.txt
cd mocks && uvicorn app:app --port 8090
```

**Без установки пакетов:** `python mocks/devserver.py`

## Адреса

| Запрос | Что отвечает |
| --- | --- |
| `GET /health` | `{"status":"ok"}` |
| `GET /fns/egrip/{inn}` | Запись ИП. У стартапа → `404 NOT_IP` |
| `GET /fns/tax-debt/{inn}` | Налоговый долг |
| `POST /bki/report` | Кредитная история (`inn` + `passport`) |
| `POST /fssp/search` | Долги у приставов (ФИО + дата рождения) |
| `GET /bankruptcy/{inn}` | Банкротство |
| `POST /passport/check` | Сверка паспорта, вариант Б |

Неизвестный человек → `404 NOT_FOUND`. Сбой для демо → `503 SERVICE_UNAVAILABLE`: у клиента T10 не отвечает бюро кредитных историй, у паспорта `9941 000008` — проверка паспорта (`data/failures.json`).

Проверить заглушки — тесты в папке `tests/` (см. `tests/README.md`).
