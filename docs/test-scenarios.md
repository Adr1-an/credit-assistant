По одному сценарию на каждого из 10 тестовых клиентов. Все цифры взяты из `tests/expected-results.json` (дата оценки 24.10.2026, настройка `EVALUATION_DATE`). Данные клиентов вымышлены.

**Клиент баллов не видит.** Баллы, зону и рекомендацию проверяем в кабинете сотрудника.
